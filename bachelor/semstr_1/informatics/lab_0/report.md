
# Отчёт по программе "Hello, C++"

## 1. Цель работы
Изучение базовой структуры программы на языке C++ и освоение процесса компиляции и запуска.

## 2. Исходный код программы

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, C++!" << std::endl;
    return 0;
}
```

## 3. Разбор программы

| Элемент               | Назначение                                       |
| --------------------- | ------------------------------------------------ |
| `#include <iostream>` | Подключение библиотеки ввода-вывода              |
| `int main()`          | Главная функция, с которой начинается выполнение |
| `std::cout`           | Поток вывода на экран                            |
| `<< "Hello, C++!"`    | Вывод строки в поток                             |
| `std::endl`           | Перевод курсора на новую строку                  |
| `return 0;`           | Успешное завершение программы                    |

## 4. Результат выполнения

```
Hello, C++!
```

## 5. Вывод
Программа успешно компилируется и выводит приветствие в консоль. Получены базовые навыки работы с потоками ввода-вывода и структурой программы на C++.
